# Changelog

## Version 1.0.0 - Initial Release (September 2026)

### Added
- Core application framework using WinUI 3
- Multi-platform device support:
  - Qualcomm Snapdragon
  - MediaTek (Helio, Dimensity)
  - Samsung (Exynos & Qualcomm)
  - Apple iOS
  - Unisoc SC/SG Series
- Device Detection Service with USB enumeration
- Firmware Management system with integrity verification
- Driver Management with per-platform support
- External Tools Management and execution
- Comprehensive Logging Service with export capabilities
- SQLite database with Entity Framework Core ORM
- MVVM architecture with Community Toolkit
- Dependency Injection setup
- Modern Windows UI with navigation

### Features
- Dashboard with device status and recent operations
- Device detection and information display
- Firmware library management
- Driver installation/uninstallation support
- Platform-specific tool integration
- System logs with filtering and export
- Structured logging with Serilog
- Automatic log cleanup
